# 🇮🇷 IRAN COLLAPSE (ایران‌کالپس)

🇮🇷 شبیه‌ساز فروپاشی، مدیریت و بازسازی ایران — بازی تلگرامی دائمی، دکمه‌محور و فارسی.

## اجرا
```
pip install requests
BOT_TOKEN=... python3 bot.py
```
یا با GitHub Actions (زنجیره ۲۴/۷): ریپو را بساز، در Settings → Secrets دو مقدار بگذار:
- `BOT_TOKEN` = توکن ربات از @BotFather
- `DEPLOY_PAT` = توکن دسترسی گیت‌هاب (برای زنجیره و ذخیره دیتا)

ورک‌فلو آماده است: `.github/workflows/bot.yml` — هر ۶ ساعت تمدید می‌شود، دیتا هر ۴۵ ثانیه commit می‌شود.

## معماری
- پایتون + threading (Workers پس‌زمینه) + قفل RLock + ذخیره اتمیک JSON
- زمان نمایش: Asia/Tehran · ذخیره: UTC
- ضدتقلب: سرور-ساید، ضداسپم، ضد جوایز تکراری، ترمیم خودکار دیتا
